Task Manager · MVVM · WPF / XAML
A desktop task management app with a clean XAML-based UI and MVVM architecture.
Create notes, prioritize tasks, set due dates, and write detailed descriptions — all in one place.

Features
✏️ Rich task editor — title, description, priority, date & time

🚦 Priority levels — low - medium - high - critical (visually highlighted)

📅 Deadline tracking — assign exact date and time to any task

📝 Long descriptions — perfect for daily plans or step‑by‑step notes

🧼 Modern UI — built with XAML and MVVM (clear separation of concerns)

Built with
WPF (.NET 6/7/8)

C# / XAML

MVVM pattern (custom RelayCommand, INotifyPropertyChanged)
